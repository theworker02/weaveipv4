# weaveipv4

Weave URLs and ipv4 query parts with stable normalization.

**Site:** https://theworker02.github.io/weaveipv4/

## Install / run

```bash
git clone https://github.com/theworker02/weaveipv4.git
cd weaveipv4
node src/cli.js
node --test
```
